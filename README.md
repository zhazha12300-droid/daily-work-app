# 个人工作台 · Workbench

一个**只在本机浏览器运行**的个人工作 / 生活管理台。包含 9 个模块，数据全部存在浏览器 IndexedDB 里，不联网、不需要登录，刷新、关闭、重启都不会丢。

## 模块

| 模块 | 做什么 |
| --- | --- |
| 首页总览 | 今日任务、快速备忘、六个模块摘要卡 |
| 今日计划 | 当天任务、专注计时、逾期任务结转 |
| 自媒体 | 选题流转（想法 → 选题 → 写作中 → 已发布）、发布排期、数据图表 |
| 开发工作 | 项目 / 条目 / 笔记 / 工时计时 |
| 咨询工作 | 客户、会话记录、待办 |
| 健身计划 | 一周训练模板、组数次数记录、体重 |
| 饮食计划 | 四餐、饮水、购物清单、热量 |
| 游戏娱乐 | 游戏库、游玩时长统计、娱乐清单 |
| 数据与设置 | 备份导出 / 导入、主题、偏好、危险操作 |

## 技术栈

- Vite 8 + React 19 + TypeScript
- Dexie 4（IndexedDB）+ dexie-react-hooks
- react-router-dom 7 · date-fns 4
- 测试：Vitest + fake-indexeddb + happy-dom

## 快速开始

需要 Node.js 20 及以上。

```bash
npm install
npm run dev        # 开发模式，打开 http://127.0.0.1:5180
```

Windows 用户也可以直接双击 `启动.bat`。

```bash
npm run build      # 类型检查 + 构建到 dist/
npm start          # 用本地静态服务器托管 dist/，默认 http://127.0.0.1:5180
npm test           # 跑全部测试（124 条）
```

> **端口固定为 5180，且只用 `127.0.0.1`。** 浏览器的本地数据按「协议 + 域名 + 端口」隔离，换端口等于换一个空数据库，看起来就像数据丢了。

## 数据与隐私

- 不联网、无后端、无账号，所有数据只存在**当前浏览器**的 IndexedDB。
- 数据按浏览器源隔离：同一台电脑、同一个浏览器、同一个地址才能看到同一份数据。
- 唯一的备份手段是「数据与设置 → 导出 JSON」。换电脑或清缓存之前请先导出。

## 目录结构

```
src/
  components/  通用组件
  db/          Dexie schema、备份、表标签
  hooks/       主题、快捷键、计时、撤销
  pages/       9 个页面
  repo/        各模块的数据读写
  styles/      设计 token 与全局样式
tests/         单元测试与交互测试
tools/         本地静态服务器
```
